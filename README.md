# Aplikasi Analisis Harga Pangan Antarprovinsi

K-Means Clustering + Linear Regression. Data: Harga Pangan Mingguan Jul-Des 2024 dan UMP 2024.

Cara menjalankan:

    pip install -r requirements.txt
    streamlit run app.py

File berikut harus berada satu folder: `app.py`, `model.py`, `charts.py`,
`data_provinsi_bersih.csv`, `panel_provinsi_bulan_bersih.csv`, dan folder `.streamlit/` (tema).
